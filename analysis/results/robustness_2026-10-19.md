## 2. Parametric bootstrap null

Per board 2000 replicates. Simulated observed scores X ~ multivariate normal with mean mu (the assumed true scores), SD sqrt(mu(1-mu)/n) and a common pairwise correlation rho (the board's headline rho), clipped to [0, 1]. Truth (i) *plug-in*: mu = observed scores. Truth (ii) *empirical Bayes*: mu_i = mean + B_i (obs_i - mean), B_i = tau2/(tau2 + SE_i^2), tau2 = max(0, var(obs) - mean(SE^2)), SE_i^2 = obs_i(1-obs_i)/n, mean = unweighted board mean. ## 7. Adjusted standard errors (Agresti-Caffo and Wilson centre)

## 9. Calibration extension

Setup as in section 2 of `robustness_2026-10-06.md` (two Bernoulli outcomes per task, phi correlation rho_true, plug-in SEs, separated when |D| > 1.96 SE_D) with the rule using an assumed rho: true, true - 0.25 and true + 0.25, clipped to [0, 0.95]. n in {30, 50, 100, 500, 2294}, P in {0.05, 0.2, 0.5, 0.8, 0.95}, rho_true in {0.25, 0.5, 0.75}: 225 cells. **20,000 replicates per cell** (fast enough; no reduction). ## 14. Systems x tasks variance decomposition and relative generalizability Ep^2

Two-way random-effects model on the systems x tasks matrix (one observation per cell, ANOVA moments; negative components set to 0): outcome = mu + system + task + residual, where the residual is the system x task interaction confounded with run noise. Ep^2 = var_systems / (var_systems + var_residual / n_tasks) = (MS_systems - MS_residual) / MS_systems is the reliability of the system means for ranking systems at the board's n tasks (relative decisions). Entries used: the kept entries of the census, every one of which has an outcome on every task (balanced by construction), so no row or column is dropped from the matrix; what is left out relative to the published leaderboard are the entries the census excluded (counted in the table; reasons in census_summary.md). For SWE-bench and TheAgentCompany a cell is a 0/1 outcome; for Terminal-Bench 1.0 (k = 5) and 2.0 (k = 1 to 10) a cell is the share of that entry's runs that solved the task, so the residual variance includes run noise divided by k. 'top 10' repeats the decomposition on the ten best entries only. Variance shares are of the total of the three components. CSV: `robustness_2026-10-19_sec14_variance_decomposition.csv`.

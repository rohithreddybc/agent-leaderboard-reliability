## Definitions and conventions

- Seed 20261019 for every random stream of this report (bootstrap_core.SEED is set to it for the new analyses; B = 10,000 bootstrap replicates, 1,000 split-half splits, 2,000 simulation replicates in section 2). The committed numbers (seed 20261008) are reproduced in section 0 and cited as 'committed' where used; every comparison of a new analysis with a baseline uses the baseline recomputed at the new seed.
- Analysis set: the 72 submissions with at least 5 trials on every one of the 89 tasks (`tb2_load.select_analysis_set`). Success: verifier reward >= 1.0; a trial with no reward counts as a failure (as in the committed analysis).
- Run-to-run resampling: tasks fixed, trials resampled within task with the N/(N-1) correction (`bootstrap_core.run_to_run`). Task resampling: tasks resampled, one draw for all submissions (`bootstrap_core.task_sampling`). Flip probability of an adjacent pair: share of replicates in which the lower-ranked submission scores above the higher-ranked one, ties half.
- f = v / (P (1 - P)), v = mean over tasks of the unbiased within-task variance p (1 - p) N / (N - 1), P = submission mean; f is undefined at P = 0 or 1. T = 89 tasks.

## 2. Overdispersion of runs

A *run* is a run directory that holds exactly one trial of every one of the 89 tasks. For such a submission with R >= 2 complete runs: m_r = mean over tasks of the run's outcomes; V = sample variance of the R run means (ddof 1); independence prediction pred = T^-2 sum_t phat_t (1 - phat_t) R / (R - 1), the unbiased within-task estimate of Var(m_r) when runs are independent and tasks fixed (T = 89; phat_t from the same R runs); ratio = V / pred. Ratio near 1: independent runs; above 1: run means vary more than independence predicts (a shared run-level effect). With R = 2 to 5 runs a single ratio is very noisy, so the null reference below simulates independent Bernoulli(phat_t) runs with the same R (2,000 replicates per submission) and computes the same ratio. Per-submission rows: `robustness_2026-10-19_tb2_overdispersion.csv`.

## 6. G-study: systems x tasks x runs

Design. Systems = submissions (random), tasks (random), runs (random). Observation X[s,t,r] in {0,1} = success of trial r of system s on task t. The run index r is the within-cell trial index of `tb2_load` (1 to 5, ordered by run directory, start time and trial name); it is an arbitrary label, so the run main effect and the systems x runs and tasks x runs interactions are expected to be near zero, and the three-way term is confounded with residual error. Only submissions with exactly 5 trials in every one of the 89 task cells enter; the others are dropped whole (no trial is discarded from a kept submission). Components are method-of-moments (ANOVA) estimators on the 0/1 scale; a negative estimate is reported as raw and set to 0 for shares and coefficients.

Expected mean squares (n_s systems, n_t = 89 tasks, n_r = 5 runs; one observation per cell):

```
MS_s   = s2_e + n_r s2_st + n_t s2_sr + n_t n_r s2_s
MS_t   = s2_e + n_r s2_st + n_s s2_tr + n_s n_r s2_t
MS_r   = s2_e + n_t s2_sr + n_s s2_tr + n_s n_t s2_r
MS_st  = s2_e + n_r s2_st ;  MS_sr = s2_e + n_t s2_sr ;  MS_tr = s2_e + n_s s2_tr ;  MS_str = s2_e
```

with s2_e the systems x tasks x runs interaction confounded with residual error. Relative generalizability coefficient for ranking systems with n_t tasks and n_r runs per task (D-study):

```
Ep2 = s2_s / (s2_s + s2_st / n_t + s2_sr / n_r + s2_e / (n_t n_r))
Phi = s2_s / (s2_s + (s2_t + s2_st) / n_t + (s2_r + s2_sr) / n_r + (s2_tr + s2_e) / (n_t n_r))   (absolute, for reference)
```

Because the run labels are exchangeable, a second fit treats runs as replicates within a systems x tasks cell (s2_w = pooled within-cell variance): Ep2 = s2_s / (s2_s + s2_st / n_t + s2_w / (n_t n_r)). It is reported as 'Ep2 (replicate model)'.

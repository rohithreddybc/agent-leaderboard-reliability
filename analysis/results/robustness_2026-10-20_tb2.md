## Definitions and conventions

- Seed 20261020; B = 10,000 replicates for every scheme. `bootstrap_core.SEED` is set to it for the within-task streams; the whole-run stream of a submission is `SeedSequence([20261020, 5, crc32(name)])`. Submissions are resampled independently of each other under both schemes.
- Identified set: submissions of the 72-submission analysis set (at least 5 trials on each of the 89 tasks) with at least 2 *complete* runs (run directories holding exactly one trial of every task) and a positive within-task variance; these are the 20 'checked' submissions of section 2 of `robustness_2026-10-19_tb2.md`.
- Whole-run resampling: R complete runs per submission, run means m_r; each replicate draws R runs with replacement and averages their means. **Small-sample rescaling:** the replicate mean is rescaled about the observed mean by sqrt(R/(R-1)), so that the resample variance is s^2/R, s^2 the ddof-1 variance of the run means (the same N/(N-1) logic as `bootstrap_core.run_to_run`).
- Within-task resampling (the paper's scheme): tasks fixed, trials resampled within task with the N/(N-1) rescaling (`bootstrap_core.run_to_run`) on ALL trials of the same submissions. 'Matched' = the same scheme on the complete runs only (differs from the paper's scheme for one submission, whose fourth run directory is not complete).
- Ratio = SD (whole-run) / SD (within-task). Flip probability of an adjacent pair: share of replicates in which the lower-ranked submission scores above the higher-ranked one, ties half; pairs are adjacent in the order by mean over all trials among the identified submissions.
- Identity: with the rescaling, analytic whole-run SD = s/sqrt(R), analytic within-task SD = sqrt(pred/R), so (ratio)^2 = V/pred, the overdispersion ratio of round 3, section 2.

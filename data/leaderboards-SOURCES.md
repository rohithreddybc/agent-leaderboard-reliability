# Leaderboard data sources (re-analysis of public agent leaderboards)

Retrieval date: 2026-10-04. Raw files: `data/raw/leaderboards/<name>/`. SHA-256 of every file: `data/leaderboards_manifest.csv` (150 files, 26.9 MB; SHA-256 of the manifest `5ca2d70635bfd07da5524ea86206fa17688c6c43cb3085b1cd103d11d89dee85`). Scripts: `analysis/leaderboards/`. Terminal-Bench 2.0 and tau2-bench are in `data/SOURCES.md` and not repeated here. Only small files were downloaded (largest 14.2 MB); nothing larger than 50 MB.

Method notes. GitHub and Hugging Face data was read through git or the GitHub API at a pinned commit. Three Google Sheets leaderboards were read once each through the sheet's CSV export endpoint (docs.google.com `robots.txt` has `Allow: /spreadsheet`; no licence or terms are stated on the sheets). The nine HAL leaderboard pages were fetched once each as HTML (the site has no `robots.txt`; no data file exists; the table was parsed locally). No page was crawled and nothing was fetched through an archive-submission endpoint. "No licence" means the repository or page carries no licence or terms; the files are public but their reuse terms are unstated.

## Census extension (2026-10-04, second pass)

The census was extended from 8 to every leaderboard that passes the written selection rule (26 pass tests T1-T3; 22 are analysed, 4 are excluded by a written criterion; `analysis/leaderboards/results/census_summary.md`, "Leaderboards analysed and excluded"). No data file was downloaded for the extension: the per-entry files of the 18 added leaderboards are the snapshot files listed above (SWE-bench Multilingual, AppWorld, BrowserGym, the WebArena and AndroidWorld sheets, MLE-bench, the HAL pages, and `data/raw/tau2` for tau2-bench airline and telecom), and the manifest (150 files, SHA-256 of the manifest `5ca2d70635bfd07da5524ea86206fa17688c6c43cb3085b1cd103d11d89dee85`) is unchanged.

Documentation pages read to verify n (page text only, one request per page, User-Agent `Mozilla/5.0 (academic census; no contact info)`, no email or personal data; `robots.txt` of arxiv.org, www.swebench.com, huggingface.co and github.com allowed each path; not saved to the project): arxiv.org abs/html pages for 2506.07982, 2407.18901, 2307.13854, 2403.07718, 2407.05291, 2405.14573, 2410.07095, 2311.12983, 2407.13168, 2404.10952, 2410.05080; https://www.swebench.com/multilingual.html; https://huggingface.co/datasets/SWE-bench/SWE-bench_Multilingual; https://huggingface.co/datasets/gaia-benchmark/GAIA and its card metadata (`/api/datasets/gaia-benchmark/GAIA`); https://github.com/ServiceNow/WorkArena and https://github.com/ServiceNow/AgentLab. The tau2-bench CHANGELOG, task files and submission guide were read through a blob-less git clone at the pinned commit `5bfa7e37` (kept outside the project). Sentences and URLs: `research/leaderboard-n-verification.md`. The GAIA `submissions_public` set (gated, no-reshare) was not accessed.

Release of derived statistics: `analysis/leaderboards/results/release/` holds only entry name, score, n, k, source URL, snapshot date and the SHA-256 of the local source file, for the kept entries, plus the entry-level exclusions with reasons. No raw leaderboard file, trajectory, contact detail or free-text source field is released. For the sources with no stated licence the author decides whether publishing even these derived numbers is acceptable.
